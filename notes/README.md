# 学习笔记草稿

本目录存放学习过程中的随手笔记与草稿，最终会整理进 `docs/` 文档站。

## 目录约定

```
notes/
├── README.md           # 本说明
├── 01-asgi/            # 阶段 1 草稿
├── 02-pydantic/        # 阶段 2 草稿
├── ...
└── _draft/             # 临时草稿（已 gitignore）
```

## 写作规范

- 每章最终成稿 ≥ 700 行，面向初学者，详细精细
- 代码示例必须可运行，附预期输出
- 架构关系优先用 mermaid 图
- 关键概念先讲"为什么"再讲"怎么做"
